# ChatPlusPlus Backend

A lightweight clone of ChatGPT’s backend capabilities built with FastAPI and PostgreSQL.  
Manages user registration, login, and chat sessions via HTTP. Supports real-time large language model responses through WebSockets. Also allows PDF and DOCX uploads for enhanced interactions.

## Live Demo

- Backend: [https://chatplusplus-backend.onrender.com](https://chatplusplus-backend.onrender.com)  
- Swagger UI: [https://chatplusplus-backend.onrender.com/docs](https://chatplusplus-backend.onrender.com/docs)
- GitHub Repo: [github.com/BrandonGatewood/ChatPlusPlus-backend](https://github.com/BrandonGatewood/ChatPlusPlus-backend)

---

## Features

- User authentication with JWT  
- User registration and login management  
- Chat and message CRUD operations  
- Real-time LLM responses via WebSockets  
- PDF and DOCX file uploads  
- Integration with Groq’s LLM API (swappable with other providers) 
- Well-documented API endpoints with Swagger UI  

---

## Tech Stack

- **Backend Framework:** FastAPI  
- **Database:** PostgreSQL  
- **Authentication:** JSON Web Tokens (JWT)  
- **LLM Service:** Groq API
- **Hosting:** Render (https://chatplusplus-backend.onrender.com)
- **Testing:** Pytest

## Architecture Overview

- **FastAPI** handles HTTP endpoints, WebSocket streaming, and API docs  
- **PostgreSQL** stores users, chats, and messages
- **JWT Auth** secures protected routes  
- **LLM API service** LLM service handles prompt streaming via Groq API 
- **File Parser** extracts text from PDF/DOCX uploads  
- **Render** hosts the live backend
- **Pytest** Business logic tested with Pytest

## Getting Started

### Prerequisites

- Python 3.12.11  
- PostgreSQL database  
- `.env` file with the following variables:
  - `DATABASE_URL` – your PostgreSQL connection string  
  - `SECRET_KEY` – secret key for JWT token signing  
  - `FRONTEND_URL` – URL of your frontend app (for CORS)  
  - `GROQ_API_KEY` – API key for Groq Cloud LLM service  

### Installation

1. Clone the repository:
  ```bash
  git clone https://github.com/BrandonGatewood/ChatPlusPlus-backend.git
  cd ChatPlusPlus-backend
  ```

2. Create and activate a virtual environment:
  ```bash
  # For macOS/Linux
  python3 -m venv venv
  source venv/bin/activate

  # For Windows
  python -m venv venv
  venv\Scripts\activate
  ```

3. Install dependencies:
  ```bash
  pip install -r requirements.txt
  ```

4. Create a `.env` file and add the following environment variables:
  ```env
  DATABASE_URL=your_postgres_url
  SECRET_KEY=your_jwt_secret
  FRONTEND_URL=your_frontend_origin
  GROQ_API_KEY=your_groq_api_key
  ```
   
5. Run the app locally with:
   ```bash
   uvicorn app.main:app --reload
   ```

### API Documentation
The backend provides autogenerated API docs via Swagger UI at:
  ```bash
  http://localhost:8000/docs
  ```

### Testing
Business logic is tested using `pytest`. To run tests:
  ```bash
  PYTHONPATH=. pytest
  ```

## Key Modules

> A quick look at the core modules in this project:

- `app/main.py` – FastAPI entry point
- `app/crud/crud_auth.py` - Database operations for user registration and login
- `app/crud/crud_chat.py` - Database operations for chats
- `app/crud/crud_message.py` - Database operations for messages
- `app/services/services_auth.py` - Authentication business logic
- `app/services/services_chat.py` - Chat-related business logic  
- `app/services/services_llm.py` - Large Language Model interaction logic
- `app/services/services_message.py` - Message-related business logic
- `app/services/services_shared.py` - Shared/common business logic across services
- `app/services/services_websocket.py` - WebSocket communication and streaming logic
- `app/routes/auth.py` – API endpoints for user registration and login 
- `app/routes/chat.py` – API endpoints for managing chat sessions
- `app/routes/message.py` – API endpoints for message handling
- `app/routes/websocket.py` – WebSocket endpoint for streaming LLM responses via Groq
- `app/core/` - JWT encoding/decoding and auth helpers
- `app/db/` - Database models and session management
- `app/schemas/` – Pydantic models used for request and response validation
- `app/util/parsers.py` – Utilities for extracting text from PDF and DOCX uploads
- `app/exceptions.py` - Custom exception classes used throughout the app
- `tests/unit/` - Unit tests covering business logic

## About This Project

This project was built independently as a way to:

- Explore backend integration with large language models (currently Groq)
- Understand and replicate core chat application mechanics, inspired by ChatGPT
- Build a fully real-time API leveraging FastAPI and WebSockets
- Implement clean authentication flows with well-structured, maintainable code
- Practice writing testable business logic

It's designed to reflect real-world backend engineering practices and prepare for production-grade system development.
